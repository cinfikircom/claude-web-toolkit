# Başlık C — Topical Authority & Topic Cluster

Amaç: Ana konu etrafında **kapsamlı** içerik kümesi kurarak hem Google'da hem AI motorlarında
"otorite" olmak. Entity SEO "kim olduğunu" söyler; topical authority "konuyu ne kadar **eksiksiz**
kapsadığını" gösterir. AI motorları kapsamlı kaynakları daha çok alıntılar.

## Pillar → Cluster modeli
```
PILLAR (ana konu, geniş rehber sayfa)
  ├─ Cluster 1 (alt konu)  ─┐
  ├─ Cluster 2 (alt konu)   ├─ hepsi pillar'a internal link verir (hub-spoke)
  ├─ Cluster 3 (alt konu)   │   pillar da her cluster'a link verir
  └─ Cluster N             ─┘
```

**Örnek (mermer tasarım firması):**
- **Pillar:** "Mermer Masa Tasarımı" (kapsamlı rehber)
- **Clusters:** mermer çeşitleri · mermer bakım rehberi · doğal taş karşılaştırmaları ·
  kullanım alanları (mutfak/banyo/salon) · mimari trendler · fiyatı etkileyen faktörler

## Nasıl yapılır
1. Sitenin **ana konusunu/konularını** belirle (iş hedefi + mevcut içerikten).
2. Var olan içeriği pillar/cluster olarak haritala.
3. **Eksik alt konuları** tespit et (rakip gap'i + kullanıcı soruları + ilgili aramalar).
4. Her eksik cluster için: önerilen başlık, kapsam, pillar'a link, birincil entity.
5. **İç linkleme planı:** pillar ↔ cluster çift yönlü; cluster'lar arası ilgili linkler.

## GEO/SEO değeri
- Google: konu otoritesi → tüm küme sıralamada yükselir (tek sayfa değil).
- AI: kapsamlı + iç bağlı içerik → "güvenilir, bütünsel kaynak" → daha fazla citation.
- Her cluster sayfası **kendi içinde alıntılanabilir chunk** (→ `references/geo-citation.md`).

## Çıktı
- **Pillar/cluster haritası** (mevcut + önerilen).
- **Eksik cluster listesi** (öncelik 🟢/🟡/⚪ + tahmini içerik).
- **İç linkleme planı** (hangi sayfa hangisine link verecek).
- Üretim Başlık F (içerik/SEO) ve D (GEO yapısı) ile uygulanır; gap kaynağı → Başlık B.
